# Preprocessor test files

`NestedTemplates` and `All_system_messages` (`.txt` input, `.expected` preprocessor tree as XML) are copied
unchanged from MediaWiki branch `REL1_39`, commit `19ddcf09181a8b7d2837b4c99e11184c53047697`
(`tests/parser/preprocess/`), where `tests/phpunit/includes/parser/PreprocessorTest.php` uses them. They are GPL
(GNU General Public License, version 2 or later; full text: `biwiki/mediawiki/COPYING`): `NestedTemplates` is
MediaWiki's own test (T29936), `All_system_messages` is text generated by MediaWiki. The other files of that folder
(`QuoteQuran`, `Factorial`, `Fundraising`) are wiki pages under GFDL / CC BY-SA and are not copied here.
`tests/test_mediawiki_preprocessor.py` runs every `*.txt` in this folder.
